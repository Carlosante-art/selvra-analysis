# Analyses

One folder per analysis, numbered. Each follows [`ANALYSMALL.md`](../ANALYSMALL.md):

1. `forregistrering.md`: question, data, thesis, falsification criterion and metric definitions. **Committed before any analysis code runs on real data.**
2. Code (SQL or Python) that reads from the dbt marts.
3. `resultat.md`: data quality decisions, results, conclusions labelled observed / derived / interpreted, limitations, log.

The commit history is the proof that the thesis came first.
